# 技能维护与验证范围

本参考用于技能维护。历史验证记录中的文档名称和主题仅说明曾经执行的检查，不用于推定新翻译任务的领域或偏好风格。

## 仓库与安装

维护仓库为 llbk-kevin/pdf-bilingual-parallel-translate，保持公开源码（暂不添加许可证），默认分支 main。全局入口为 <CODEX_HOME>/skills/pdf-bilingual-parallel-translate。新建的普通目录在 CC Switch 接管前留在原处，不手动迁移。

编辑前检查入口是否为链接并解析其目标，在实际目录维护。修改后确认原链接仍指向同一目标，且从入口能读到更新。尚无链接时直接维护普通目录。发现断链或独立副本分歧时，先报告，不擅自替换。

## 维护流程

明确要求修改本技能时，同步 SKILL.md 和 README.md，同时同步被修改的英文参考与 .zh-CN.md 版本，命令、格式标识和示例保持等价。普通使用读取英文入口；中文文档用于用户审阅与维护。

在合适的 Python 环境安装 requirements-dev.txt，并从实际技能目录运行：

~~~
python -m unittest discover -s tests -v
python scripts/pdf_tools.py --help
~~~

集成测试使用 ReportLab 和 pypdf 在临时目录生成小型 PDF，不依赖桌面文档或授权字体文件。运行工具需要 pypdf、pypdfium2、Pillow、fonttools，开发和可选构建范例另需 ReportLab。首版在 Windows 验证的版本为 pypdf 6.10.0、pypdfium2 5.13.0、Pillow 12.3.0、ReportLab 4.4.9。依赖文件允许兼容的小版本更新，更新后应重跑相关测试。资源清点有意使用 pypdf 6.x 的编码流内部接口，大版本升级需复核。

若安装的 skill-creator 提供校验器，则运行它，并检查 UTF-8/BOM、Markdown 链接和界面元数据。提交前检查 git diff 与跟踪文件，排除任务输入、输出、状态、渲染缓存、字体二进制和凭据。提交采用 Conventional Commits，英文 type/scope、中文说明；实质变更附多行中文正文。.gitignore 各组保留中文注释。

选定维护策略为验证后提交并推送 origin/main，不强推、不丢弃无关工作。远端有新提交时先获取并只整合已理解的变更，再验证结果。认证或推送失败时保留本地提交，如实说明剩余步骤。普通 PDF 翻译不修改或同步本仓库。

## 限制与后续变更

本技能不含自动翻译或统一排版引擎。翻译、原文清单覆盖和逐页查看仍由模型完成。工具不能可靠识别每一处漏句、表格扁平化、图注错位、裁切字形、ToUnicode 缺失或阅读顺序问题，启发式检查有意设为警告。有状态清单时图形提示使用明确的图注块，无清单时匹配唯一可提取图号；错误清单、重复引用和图片内图注仍可能造成遗漏或误报。字体覆盖检查验证声明的实际绘制片段及源字体，不检验最终 PDF 每个字形程序；审阅证据验证一致性，不证明审阅者理解了内容。

自动结构检查不证明无障碍结构、表单行为、图层语义、数字签名有效性或完整书签层级等价，交付说明应保留这些边界。后续根据具体失败补充测试；没有相应用户需求时，不扩展为大型排版引擎或硬编码厂商规则。

## 默认原位翻译（状态 v3）

默认流程在两侧复用完整原页，仅删除选中的右侧原生字形，并局部绘制中文。旧范例保留为显式 v1/v2 兼容构建器，不自动回退。新恢复状态记录不可改写的源字形事实、归属/范围、处理方法、允许/实际边界、真实字体分配及源几何/指纹，详见 [inplace.zh-CN.md](inplace.zh-CN.md)。

新增二十项程序生成回归覆盖：同源共享图片与软遮罩及嵌套 Form、左侧像素隔离、彩底与保留公式、裁切/旋转/UserUnit/混合尺寸、隐藏 OCR 与转曲标签覆盖、溢出和原文变化、字形拆分及零宽连字尾字、真实轮廓碰撞、英文词/型号换行、有界字号拟合和上下标基线、字体共享/子集化及可重复性、原始 nullable 链接模式、旋转目标和随译文重排的点击锚点、启用可见批注的静态外观迁移及左右独立对象、不支持的批注/文字剪裁、允许布局框内仍能检出图形损坏的精细右侧区域检查、外部输入保留、新增编号。测试不含用户 PDF/字体二进制。真实样本试用及审阅证据留在文档任务文件夹。

已核验的实现细节：全局 deflate 可能重编码源图像，因此仅压缩非图片流；PDFium 忽略 UserUnit，因此仅在内存渲染副本规范化；MuPDF glyph_bbox 可能返回字体全局框，因此译文墨迹边界采用 fontTools 轮廓，源碰撞/掩码采用绘制 trace；get_links 无法可靠表达 nullable XYZ 坐标，迁移直接读取原 PDF 目标数组；字体序列化禁止重算时间戳。这些是实现验证，不保证任意布局均无需人工复核。

## 阅读流程入口与样本范围

pipeline 对新任务默认 practical，脚本冻结在 authoring state 旁；缺少模式字段仍按严格语义。入口批量处理 JSON 编辑与段落合并，复用指纹匹配构建，合并审计与图片渲染，单独登记真实观察，按相同字节发布并自动生成说明。显式样本保留源页映射，记录省略的范围外链接。

新增流程回归覆盖样本完整性与旧整本范围、原子编辑与合并字形归属、空字号下限、审计/渲染缓存、未查看状态拒绝、精确右侧差异处置且不可豁免原文损坏、未变页审核史复用、共享字体失效、相同字节发布、局部/重复资源构建、无目标书签标题及嵌套跳转。夹具观察是合成记录，不声称人工验收。真实独立试用、耗时、token 统计及保留问题写在仓库外的任务报告。

独立七页阅读模式试用暴露两类具体问题：猜测像素换算倍率使扫描覆盖压到图纸，改回 live 入口使审核目录推算失效。像素编辑现核对原图指纹及记录 DPI；覆盖观察须对照其下图纸/表格。review 读取已绑定证据，核验缓存不依赖无关入口代码变更。90 项合成回归通过，含这些修复。独立复查接受剩余细小痕迹，不再调整版面。保留历史试用记录；live 到冻结构建器路径迁移仍会保守地使页语义哈希失效，即使像素相同，这次迁移不能声称自动复用了审核。

## 双路阅读模式试用后续

第二轮独立试用暴露了链接映射逐条报错，以及逐条修正意外替换整页链接列表的问题。现在链接冲突集中返回页码、链接编号及坐标；link_overrides_patch 按 source_link 更新单项，旧整页列表替换仍保留明确语义。复用页观察同时保留精确匹配的已接受发现和页说明，避免未变的无害差异阻断局部修复交付。93 项程序回归通过；链接迁移修订后的真实受影响页重建像素一致。两处不安全的图片标签覆盖已局部修正并独立复查；DPI 正确或 covers_checked 标志并不证明位置安全，应以可辨认尺度读取邻近数值，不为美观残影再启动全书检查。


重复字母连字可能产生与可见承载字形具有相同字符及原点的零宽追踪尾项。有效边界忽略空追踪项，避免其覆盖承载字形；原始字形事实及所有权检查保持不变。新增 ff 合成夹具复现旧故障，并验证替换和左侧原文隔离。
