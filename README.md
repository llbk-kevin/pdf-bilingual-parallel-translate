# PDF 双语平行对照翻译

## 工作约定

使用当前会话模型翻译，不调用外部机器翻译。每次翻译前，检查当前 PDF 的实际内容，识别语言、主题领域、文体、预期读者和版式，据此选择术语、表达方式及适用检查项。不根据此前翻译任务推定本次领域；无法确定的分类保持暂定。遵循用户明确选择。

采用 UTF-8 无 BOM。使用技能时只读英文 SKILL.md 和相关英文参考，不读中文 README.md。维护时同步两种语言。任务文件放在本仓库外。解析安装目录；保留 CC Switch 链接并在本体维护，不自行迁移。

默认任务结构（用户指定位置时遵从指定）：

~~~text
<source-directory>/
|-- <source-stem>.pdf
+-- <source-stem>/
    |-- <delivery-name>.pdf       # 仅放已验收输出
    |-- 交付说明.md
    |-- recovery/                # 状态、构建器、术语及重新生成说明
    +-- work/                    # 草稿、提取、渲染、审计与断点
~~~

根据内容识别角色，不以中文文件名或翻译后缀判断。源文件重命名前展示具体新旧名称对照表；普通模式确认后改名，已接受的 Plan 中有对照表时无需二次确认。不得覆盖原文或冲突目标；除非明确要求删除，否则保留旧译稿。仅在确认当前文档属于 TI 后，读取并应用 [naming.zh-CN.md](references/naming.zh-CN.md)。

恢复路径尽可能相对化。记录外部原文 SHA-256、字体名称/指纹/获取来源、依赖和构建参数。状态是译文及布局的权威输入，不是硬编码 Python 译文的附录。先把范例及辅助模块复制到任务恢复包再调整。

## 交付要求

1. 完整、准确、原文保真和可读性是交付条件；其次优化空间对应，再考虑排版。不得为适应空间省略限定条件、混合不同含义或过度缩小文字。
2. 每个原文页对应一个输出页。左侧可见原文保持 1:1，中文区默认同宽同高。语义块及分栏对应，不要求逐行一致。
3. 根据原文实际包含的内容建立清单：标题、段落、列表，以及存在的表格单元格、公式、图注或必要图内标签。保留阅读顺序及跨页上下文。合并提取碎片时保存来源映射；区分图片内标签、重复提取及不可见文字。对照可见原文检查清单。
4. 核对完整性、含义、语气、否定、条件、限定和专有名称。原文包含相关内容时，再核对数字、单位、正负号、比较符号、正比/反比及上下标，保留重复公式与真实表格结构。参见 [layout.zh-CN.md](references/layout.zh-CN.md)；原文含数学表达时读取 [math.zh-CN.md](references/math.zh-CN.md)，优先保留易读结构，避免 ASCII 替代。
5. 原文有图形时保留在左侧，右侧附近放对应图注及有标识的标签、图例和坐标说明。通过图号、原标签或准确位置消歧。有效留白可以保留；不添加空色框、虚构图形或集中于页顶的图注。
6. 依次改善换行、列宽及间距，再利用邻近空间重排，最后适度加宽中文区。原文区保持不变。完整、可读、同页对应仍无法实现时明确报告未解决页。
7. 保留原文中无法确认的含义。记录页码、块、原文、疑点及处理；建议校正是可选项，必须有依据。影响含义的矛盾在相应位置简要提示，完整问题保留于恢复和交付说明。不得静默纠错或把猜测当事实。
8. 复用原图片编码和质量。中文使用可搜索、可复制的文字及轻量矢量；字体全书共享并子集化。备用字体针对具体缺字分配。检查每个片段实际使用的字体，再查看最终渲染字形。
9. 从原文和状态重新生成，不叠加旧双语 PDF。构建器必须读取状态中的译文、完整单元格和布局，不覆盖输入编辑。明确命名的草稿放在 work/。

合成及结构验收前读取 [pdf-integrity.zh-CN.md](references/pdf-integrity.zh-CN.md)；创建或迁移恢复资料前读取 [state-and-qc.zh-CN.md](references/state-and-qc.zh-CN.md)。

## 工具与构建接口

诊断使用 Python 3.10+ 和 requirements.txt；可选范例另需 requirements-dev.txt。先发现解释器，优先使用合适的现有或隔离环境；不能只为绕过 Shell 故障就安装到共享 Python。必要时直接调用解释器，不在技能中写死本机运行时路径。

~~~text
python -m venv work/pdf-skill-env
<venv-python> -m pip install -r "<skill-dir>/requirements-dev.txt"
<venv-python> "<skill-dir>/scripts/pdf_tools.py" --help
~~~

| 入口 | 输入 | 输出与用途 |
| --- | --- | --- |
| inspect SOURCE --out baseline.json | 原文 | 几何、提取、链接书签及可达资源。 |
| audit SOURCE FINAL --state state.json --out audit.json | 原文、成品、可选映射 | 固定比例原文对比、资源、链接、体积及内容流问题。 |
| render FINAL --source SOURCE --state state.json --pages all --out renders | 成品、可选原文/映射 | PNG 及包含文件/像素/内容/设置指纹的不可改写索引，不记录已查看。 |
| check-fonts state.json --assignments final.font-runs.json --out fonts.json | 状态及实际绘制片段 | 分配字体覆盖、缺字、回退使用及未验证字体。 |
| check-state state.json --final --out state-check.json | 状态及引用证据 | 一致性、指纹、覆盖和审阅记录；处理中省略 --final。 |
| scripts/example_build.py --source SOURCE --state state.json --output work/draft.pdf | 显式边界、登记字体及完整状态 | 确定性 PDF、draft.state.json 和 draft.font-runs.json；输入状态只读。 |

范例是构建模式，不是通用排版引擎。要求未旋转、未裁切、零原点页面，遇不支持的几何或溢出会失败。其他情况需明确适配；[building.zh-CN.md](references/building.zh-CN.md) 说明字体、表格及独立副本重建。

含空格路径加引号。报告、渲染和范例在没有 --overwrite 时拒绝覆盖，原文始终受保护。--pages 接受 all 或从 1 开始的 1,3-5 等选择。默认对比设置为 144 DPI、4000 万像素、RGB 容差 16、变化比例 0.001，不是翻译质量阈值。调查差异，不放宽阈值掩盖问题。空用户密码 PDF 直接支持；需要密码时通过 --password-env 指定用户提供的环境变量，不保存或记录密码。

诊断退出码：0 为机械检查完成且无错误（可能仍有警告）；2 为报告检查失败；1 为运行失败。ready_for_delivery 是一致性兼容字段，不是语义认证；quality_certified 保持 false。版本 1 状态标为旧版声明，不静默升级为版本 2 证据。

## 工作流程

1. 检查当前 PDF 的语言、主题领域、文体、预期读者和版式，据此选择术语、表达方式及检查项，无法确定的分类保持暂定。识别角色、命名及路径；检查原文并保留指纹和资源基线。渲染代表性页面，核对提取/OCR 及实际存在的数字符号，再选择文档适用的字体、字号、颜色和安全边距。
2. 按阅读顺序建立语义块、跨页依赖及上下文术语。按连贯段落或上下文组翻译，先试排代表页再扩展；每批保存状态。
3. 从原文及状态构建，构建时检查字形，对实际绘制片段运行 check-fonts。检查草稿状态，查看渲染样页并修复溢出，以及实际存在的表格几何或数学表达问题。保存准确的批次/队列断点，不在技能中嵌入账号余额或临时额度政策。
4. 在独立副本验证恢复：重建，修改一个实际存在的译文块；有表格时再修改一个单元格，确认输出变化且输入编辑保留。不要仅为执行此检查而新增表格。重复生成不得累积资源。字节一致有参考价值；仅元数据变化时说明原因。
5. 完成保存、字体子集化、无损内容压缩及资源清理。冻结候选版本、计算指纹并审计。逐页/逐资源调查警告并保留原报告；已证明的工具缺陷需明确绑定的替代证据，不能编辑通过标记。
6. 分别进行翻译、视觉和结构验收。首次实际查看所有完整页面并放大密集细节；拼图只作导航。返修后全书重渲染及结构检查，变化页重新看；只有像素、渲染设置、文字/布局、语义依赖一致且原记录可追溯时才能复用，否则重新查看。
7. 仅记录实际审阅：页码、查看者/时间/证据、PDF/渲染/内容指纹及复用理由。check-state --final 验证记录，不能证明模型理解了页面。渲染或机械成功不能证明准确。
8. 交付 PDF/恢复资料，说明页数、原文及译本大小、绝对/比例增长、资源增量、覆盖和疑点。如实说明未完成工作。仅路径改名保留旧验收和已验证迁移链，不替换旧哈希冒充新审阅。

明确维护技能时遵循 AGENTS.md 及 [maintenance.zh-CN.md](references/maintenance.zh-CN.md)。普通翻译文件不进入本仓库。
