# 双语 PDF 原位翻译

生成可独立阅读的双语 PDF：左侧原页，右侧复用原图并原位排中文，两侧保持原页可见尺寸。按完整段落和表格单元格翻译，适当保留原生公式、数值、单位和标识，原文字形事实不可改写。

默认 **practical**：原文完整、所需页面齐全，中文、表格和主要图形可读。轻微残字、断行和美观差异可简要记录后保留。修复主要漏译、公式或数值损坏、正文不可读和主要图形遮挡。明确要求时才用 **strict**。不设固定耗时、token 或代理数量上限。

## 开工与角色

主代理先读 [命名规则](references/naming.zh-CN.md) 与 [集群流程](references/coordination.zh-CN.md)，核对文档身份，同时展示**精确命名表和代理工作表**。列明原文、译本、工作目录、职责与页段、模型与强度以及交接位置。包含这些表格的计划已获接受时直接沿用。续跑查阅已确认决定，仅对拟变更的名称、位置或模型重新确认。完成批准的改名与原文哈希核对后，再 prepare 和翻译。

每份 PDF 有译者／状态写入者，以及全新上下文的独立复核者。长文档可以分给多个页段负责人，动态安排并发，修复优先续用原代理。主代理负责技能问题定位和代码维护。

按角色读取材料：

- **主代理：**[集群流程](references/coordination.zh-CN.md)，负责准备、派工、页段合入与发布。
- **译者：**[翻译实操](references/practical.zh-CN.md)，负责分组、编辑、预览和页段交付。
- **复核者：**[复核实操](references/review.zh-CN.md)，负责实际查看、通过／待修决定和证据。
- **维护者：**AGENTS.md 与[维护说明](references/maintenance.zh-CN.md)。几何与状态细节见[原位构建](references/inplace.zh-CN.md)及[状态与复核](references/state-and-qc.zh-CN.md)。

## 流程与文件

确认 → prepare → 翻译／apply → build → verify → 独立 review → publish。使用冻结入口返回的精确动作数组。编辑和构建使用作者状态；核验、复核和发布使用候选状态。命令会拒绝用途不符的状态。

同名工作目录外只放原文和正式译本：

~~~text
<原文stem>.pdf
<原文stem>_双语左右对照翻译.pdf
<原文stem>/
    交付说明.md
    recovery/                 # 作者状态与冻结环境
    work/                     # 分包、候选、观察和日志
        rebuild/              # 可选恢复实验
~~~

使用 UTF-8 无 BOM。apply 保存编辑，import-package 合入分配的页段，review 登记真实观察。生成模板绑定路径与证据，不手工修改 qc 或原文字形事实。局部预览留在工作目录。普通发布核对恢复依赖，完整恢复重建用于维护或用户明确要求。

## 安装与条件工具

在 Python 3.11+ 环境安装 requirements.txt，prepare 时提供中文字体。仓库不附带字体。保留 CC Switch 链接，通过解析后的本体维护。

状态查询和长日志使用短生命周期 CLI 进程。使用持久 Node 内核或未托管后台作业时，读取[工具运行说明](references/tool-runtime.zh-CN.md)，完成登记、托管与清理。渲染不等于查看，代理完成也不等于工具内核退出。
